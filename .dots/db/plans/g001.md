# g001: Migrate Kiosk Script to Electron Shell

## Problem

The current kiosk launcher requires Chrome/Chromium to be installed on the system and loads the app from GitHub Pages. This creates external dependencies and requires internet connectivity. An Electron shell would make Buddy self-contained and work offline with local builds.

## Solution

Create an Electron application that:
1. Serves the local Vite build (`dist/`) 
2. Opens in a frameless window mimicking the current Chrome app mode
3. Replaces the `launch-kiosk.sh` script with `npm run kiosk`

## Key Decisions

- **Local build over remote URL**: Load from `dist/` instead of GitHub Pages for offline capability
- **macOS primary target**: Focus on macOS first, other platforms can be added later
- **Frameless window**: Match current Chrome `--app` mode aesthetic (no browser chrome)
- **Electron over other solutions**: Bundles Chromium internally, same rendering as current Chrome setup
